# 🐾 Aumiau — Pet Shop Landing Page

Aumiau is a fictional pet shop landing page designed to provide a fun, welcoming, and engaging digital experience for pet owners.

The project combines playful visual elements, modern web design, and responsive layouts to create a unique online presence for a pet care business.

## 📌 About the Project

Aumiau was developed as a portfolio project to demonstrate how creative design and web development can help pet shops establish a stronger digital presence.

The website focuses on presenting the brand, highlighting its services, and making it easier for customers to find information and get in touch.

**Note:** Aumiau is a fictional brand created exclusively for demonstration and portfolio purposes.

## ✨ Features

- Creative and playful visual identity
- Modern and responsive layout
- Engaging visual elements and interactive effects
- Service presentation sections
- Clear navigation and intuitive user experience
- Contact-focused calls to action
- Mobile-friendly design

## 🛠️ Technologies

- **HTML5** — Semantic structure
- **CSS3** — Styling, layouts, and animations
- **JavaScript** — Interactions and dynamic behavior

## 🎯 Project Goals

- Develop a distinctive visual identity for a fictional pet shop.
- Create an enjoyable browsing experience.
- Ensure compatibility across desktop, tablet, and mobile devices.
- Apply modern front-end development practices.
- Demonstrate creative web development skills through a real-world-inspired project.

## 📱 Responsive Design

The website is designed to adapt to different screen sizes while maintaining visual consistency, readability, and usability.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   `git clone https://github.com/YOUR-USERNAME/aumiau.git`

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.
